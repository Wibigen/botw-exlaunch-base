# BOTW Exlaunch Base

An Exlaunch base by **WibiDev** for creating **EXEFS mods** for **The Legend of Zelda: Breath of the Wild**.

# Important

This codebase is **only compatible with** **The Legend of Zelda: Breath of the Wild v1.5.0**.

Mods built with this project **will not work** on any other game version.

# Project Structure

The main source file is located at:

```text
source/program/main.cpp
```

# Building

To compile the project, simply run:

```bash
make
```

The compiled files will be generated in:

```text
deploy/main.npdm
deploy/subsdk9
```
